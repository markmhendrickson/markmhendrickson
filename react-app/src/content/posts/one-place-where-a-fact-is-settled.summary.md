- A changed fact, such as a due date moved by a later email, leaves agents in different tools answering differently.
- Recall finds related material, but it does not say which source is current.
- Neotoma stores each write as an observation linked to its source, and a merge rule per field computes the current value.
- Each current field names the observation and source that set it, and one entity can be read as of an earlier time.
- Larger parts of the design are not built yet: whole-record reads as of a past date, moving a record with its history, corrections that always hold, and verified authorship for every write.
